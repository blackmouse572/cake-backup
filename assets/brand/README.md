# Brand assets

The "Doorway" logo: an ink `#111111` arch with a route-blue `#0090FF` person, and a Geist Serif wordmark. Red and green are reserved for alerts and never appear in the logo.

- `cage-symbol*.svg`: the mark alone (`-small` is tuned for small sizes, `-ui` for in-app use, `-reversed`/`-white` for dark grounds).
- `cage-horizontal*.svg`, `cage-stacked*.svg`, `cage-wordmark.svg`: lockups.
- `cage-app-icon*.svg`, `cage-android-foreground.svg`: app icon sources.
- `cage-disguise-notes.svg`: the neutral icon used in disguise mode.
- `web/`: rendered PNGs, favicons, `site.webmanifest` and a `head-snippet.html` for the live-map web page.

Never show the Cage logo on check-in call screens or anywhere disguise mode is on. Don't use a shield icon as the logo.
